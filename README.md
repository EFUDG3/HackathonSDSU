# ClubHub

ClubHub is an AI-powered web prototype built during the Innovate4SDSU Hackathon to help student organizations centralize resources, manage finances, and reduce administrative overhead. The project focuses on streamlining club operations by combining modern full-stack development with LLM-powered information retrieval.

---

## 🚀 Why ClubHub?

Student organizations often rely on scattered tools, spreadsheets, and documents to manage finances, policies, and resources. ClubHub was created to:
- Consolidate key organizational information into a single platform  
- Improve transparency in club budgeting and spending  
- Reduce time spent searching for administrative or club-related information  

---

## 🛠 Tech Stack

**Frontend**
- React.js

**Backend**
- FastAPI (Python)

**Database & Auth**
- Supabase (PostgreSQL)
- `pgvector` for semantic search

**AI / LLM**
- Gemini API
- LangChain (RAG orchestration)

---

## ✨ Key Features

- **Interactive Financial Dashboard**
  - Real-time budget and transaction tracking for student organizations  
  - Data synced directly from PostgreSQL via Supabase and FastAPI  
  - Designed to support transparency and informed financial decision-making  

- **RAG-Powered AI Assistant**
  - LLM-based assistant for answering club and administrative questions  
  - Uses LangChain, Gemini API, and vector search to retrieve relevant information  
  - Reduces manual lookup time for policies, procedures, and resources by over 1 hour per user  

- **Centralized Resource Management**
  - Single hub for club-related data, documentation, and workflows  
  - Built to scale with additional features such as role-based access and analytics

## 👥 Team & Development
